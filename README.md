# MY LITTLE UNIVERSE

一个沉浸式的个人灵感 / 收藏墙。
React + TypeScript + Tailwind CSS + Framer Motion。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 部署（Vercel）

推送到 GitHub 后，在 [vercel.com](https://vercel.com) 导入本仓库即可：

- Framework Preset：**Vite**（自动识别）
- Build Command：`npm run build`（默认）
- Output Directory：`dist`（默认）

`vercel.json` 已配置 SPA 重写，深层链接（如 `/item/xxx`）刷新不会 404。

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FYYou66%2FLiHai)
